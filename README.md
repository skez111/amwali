# أموالي — تطبيق إدارة مالية شخصية

تطبيق ويب عربي خفيف لإدارة الدخل الفعلي والمتوقع، المصروفات، الالتزامات وسدادها، وتحليلات مبسطة. لا يحتاج إلى مكتبات خارجية أو حساب مستخدم.

## التشغيل

من داخل مجلد المشروع:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح. للتثبيت والعمل دون إنترنت على iPhone أو iPad، انشر الملفات على استضافة **HTTPS** ثم اختر «إضافة إلى الشاشة الرئيسية». يدعم Service Worker التخزين المؤقت بعد أول زيارة ناجحة.

## ما يعمل

- حفظ دائم محلي باستخدام IndexedDB.
- إنشاء وتعديل وحذف التزامات بأقساط اختيارية، واحتساب المتبقي من سجل السداد.
- تسجيل سداد كامل أو جزئي وربطه تلقائيًا بكشف حركة الأموال.
- دخل فعلي أو متوقع، واستلام جزئي من دخل متوقع.
- مصروفات بفئات مبسطة، والفصل بين سداد الدين والمصروفات الاستهلاكية.
- فصل حصيلة القرض عن الدخل المكتسب.
- عرض رئيسي مبسط وفلاتر زمنية وتحليل لأوجه الإنفاق.
- نسخ احتياطي واستعادة JSON وتراجع عن آخر تغيير داخل الجلسة.
- RTL، تصميم متجاوب، وضع فاتح وداكن حسب إعداد الجهاز.

## حدود الإصدار الحالي — مهم

- **لا توجد مزامنة بين الأجهزة أو حسابات مستخدمين أو حماية خادمية**. بيانات كل متصفح مستقلة؛ استخدم النسخ الاحتياطي لنقلها يدويًا. لا تحفظ معلومات شديدة الحساسية فيه على جهاز مشترك.
- لا يوجد عرض تقويم كامل ومتجدد للأقساط الشهرية؛ حقل الاستحقاق الحالي يُحدث يدويًا. إجمالي الـ30 يومًا تقديري للاستمارة المسجلة، وليس جدولة آلية للدفعات المتعددة.
- لا توجد إشعارات نظام التشغيل أو رسوم الاتجاهات التاريخية أو ميزانية مستقبلية.
- يجب اختبار المبالغ والعمليات بمزيد من اختبارات التكامل قبل الاعتماد عليه للقرارات المالية المهمة.
- ملفات PWA لا تحتوي على أيقونات مخصصة بعد.
- يمكن إضافة Supabase أو Firebase لاحقًا بعد تصميم مصادقة وحماية صلاحيات لكل مستخدم وتسوية التعارضات عند المزامنة.

## النموذج المالي

المبالغ مخزنة كأعداد صحيحة من الهللات. المدفوعات مستقلة عن سجل المصروفات، لكنها تظهر في السجل الموحد ديناميكيًا؛ وبالتالي لا تسجل مرتين. الرصيد المتبقي للالتزام = أصله المسجل − مجموع مدفوعاته. الدخل المتوقع لا يدخل ضمن الدخل الفعلي، وعمليات الاستلام الجزئي مرتبطة بالأصل المتوقع.

## الخصوصية

لا يرسل التطبيق البيانات إلى أي خادم. قد يمسح المتصفح بيانات التخزين المحلي لأسباب تتعلق بالنظام أو إعدادات الخصوصية؛ لذلك استخدم تصدير النسخ الاحتياطية بشكل منتظم.
